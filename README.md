# مراقب حجوزات Spor İstanbul

أداة بتراقب صفحة اختيار الجلسات على `online.spor.istanbul` كل 7 دقائق، 24 ساعة / 7 أيام.
لما يصير في مربع **أخضر** (مكان متاح للحجز) بتنبّهك فوراً:
- 🔊 **صوت إنذار** على الكمبيوتر
- 📱 **رسالة تلجرام** على موبايلك (اختياري — إعداد مرة وحدة)

---

## ملفاتك

| الملف | شو بيعمل |
|------|----------|
| `config.json` | بياناتك والإعدادات (كلمة السر مخزّنة هون — خلّيه خاص) |
| `setup.bat` | **شغّله مرة وحدة** أول شي — بينصّب كل شي |
| `test.bat` | تجربة: بيفتح متصفح ظاهر، بيسجّل دخول، وبيوريك شو لقّط |
| `run.bat` | **التشغيل الفعلي** 24/7 — خلّي النافذة مفتوحة |
| `get_telegram_chatid.py` | مساعد لربط تلجرام |
| `monitor.log` | سجل كل الفحوصات (بينعمل تلقائياً) |

---

## خطوات التشغيل

### 1) التنصيب (مرة وحدة)
دبل-كليك على **`setup.bat`** وانتظر لحد ما يخلص.

### 2) التجربة (مهم قبل التشغيل الطويل)
دبل-كليك على **`test.bat`**.
رح يفتح متصفح، يسجّل دخول، ويطبع كل المربعات مع ألوانها — كم مربع أخضر لقّط.
هيك بتتأكد إنو تسجيل الدخول والكشف شغّالين. بعدها بتسكّر النافذة.

> إذا فشل تسجيل الدخول: تأكد من `tc` و `password` بملف `config.json`.
> إذا الموقع طلب رمز تحقق (SMS) وقت الدخول — خبّرني لأعدّل الطريقة.

### 3) التشغيل 24/7
دبل-كليك على **`run.bat`** وخلّي النافذة مفتوحة.
بيفحص كل 7 دقائق، وإذا صار أخضر بيرنّ الإنذار (+ تلجرام إذا مفعّل).
إذا وقع أو انقطع النت، بيرجع يشغّل حاله تلقائياً.

لإيقافه: سكّر النافذة.

---

## ربط تلجرام (اختياري بس مفيد — بيوصلك عالموبايل)

1. بتلجرام، ابعت رسالة لـ **@BotFather** → اكتب `/newbot` → اتبع الخطوات → رح يعطيك **توكن** (شي متل `123456:ABC...`).
2. افتح `config.json` وحط التوكن جنب `"telegram_token"`.
3. افتح البوت الجديد تبعك بتلجرام وابعتله أي رسالة (متلاً `hi`).
4. شغّل: `py get_telegram_chatid.py` — رح يلقط رقم المحادثة ويحفظه ويبعتلك رسالة تأكيد.

خلص! من هلق رح توصلك الإشعارات عالموبايل.

> إذا ما بدك تلجرام، اتركه فاضي — صوت الإنذار عالكمبيوتر بيشتغل عادي.

## الإعدادات (`config.json`)

| المفتاح | المعنى |
|--------|--------|
| `check_interval_minutes` | كل كم دقيقة يفحص (افتراضي 7) |
| `renotify_cooldown_minutes` | إذا ضل نفس المكان أخضر، بعد كم دقيقة يعيد التنبيه (افتراضي 15) — عشان ما يزعّجك كل 7 دقايق |
| `headless` | `true` = المتصفح مخفي (للتشغيل الطويل). `false` = ظاهر |
| `alarm_sound` | `true`/`false` صوت الإنذار |
| `alarm_beeps` | كم مرة يرنّ |
